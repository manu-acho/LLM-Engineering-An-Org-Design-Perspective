# Lesson notebooks

Begin with `01-foundations/01-model-and-application.ipynb`, then follow the module routes. Every lesson has a mapped notebook; `study-manifest.json` records the pairing. Read the Markdown lesson alongside it for the full conceptual and organisational argument.

Select the project `.venv` kernel and run cells from top to bottom. Notebooks are saved without outputs. The shared implementations live under `src/ai_orgdesign/labs` and the pilot's `examples/01-foundations` folder. The default route makes no paid-provider call. Recommended live cells state their network and cost behaviour. Set COURSE_LIVE_MODE=1 in the private root .env to run them with your key. Downloading CPU models has a separate switch. Routine verification forces live calls off. See the [live-model guide](../reference/live-model-guide.md).
