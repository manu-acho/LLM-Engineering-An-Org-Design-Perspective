# Agent engineering within the standalone curriculum

[Full curriculum](CURRICULUM.md)

Part II is planned as Modules 9 to 14. It will build on the foundations to teach bounded loops, accepted handoffs, specialist teams, durable state, framework choices and MCP capability interfaces. Part III then examines how those mechanisms enter business implementation and operations.

The first available study unit is [Module 1](modules/01-standalone-foundations/README.md). The distinction it introduces between evidence, generated language and permitted action carries through the planned agent material. Agent implementations from the companion edition have not yet been rewritten as complete standalone units and are not published as such here.
