# Course curriculum

[Start here](START-HERE.md) · [Glossary](reference/glossary.md) · [Verification](reference/verification.md)

Twenty modules connect technical understanding with the design of work. Read in order for the full implementation route. Business readers can follow concepts, organisational cases and design exercises while using code outputs as evidence about the mechanism.

Before Module 1, read [Meet Harbour](HARBOUR.md). The [Harbour learning journey](reference/harbour-learning-journey.md) connects each module to a specific business situation and design output.

## Completion and evidence

Each route supplies concepts, implementation explanations, examples, alternatives and exercises. Available teaching material is distinct from tested external deployment: the [verification guide](reference/verification.md) records what runs locally and what still requires accounts, opt-in calls or a separate operating environment. The cumulative workbook asks for a defensible technical and organisational design, not a claim that fictional examples establish real business outcomes.
